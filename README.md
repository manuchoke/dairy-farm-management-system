#Dairy Farm Management System

Overview

The Dairy Farm Management System is a web application designed to streamline and manage various aspects of dairy farming. It provides essential functionalities to monitor and manage animals, milk production, feed consumption, health records, sales analysis, dairy news, reports, and an AI-powered dairy chat assistant.

Features

#1. Animal Management

Displays all animals on the farm.

Provides detailed records for each animal.

#2. Milk Production

Keeps track of daily milk production.

Calculates morning and evening total milk per animal.

Displays daily, weekly, monthly, and yearly milk production.

Provides an automated running total for each year.

#3. Feed Management

Manages feed quantity and cost.

Tracks feed consumption per animal.

Analyzes feed data using charts.

#4. Health Records

Facilitates medical functions such as:

Lab tests

Medication tracking

Reproductive health monitoring

Vaccination records

General health checks

#5. Sales Analysis

Analyzes milk production and feed consumption.

Displays data insights using interactive charts.

#6. Dairy News & Reports

Provides news and reports concerning dairy farming.

Helps users stay updated on industry trends and best practices.

#7. Dairy Chat AI

AI-powered chat assistant for answering dairy farming-related questions.

Provides insights and best practices for farm management.

Technologies Used

Frontend: React.js, Tailwind CSS

Backend: Node.js, Express.js

Database: MongoDB

Charts & Visualizations: Chart.js / Recharts

AI Chat Assistant: AI-based integration for user queries

#Installation and Setup


Backend Setup:

cd backend
npm install
npm start

Frontend Setup:

cd frontend
npm install
npm start

Access the application:

Open http://localhost:3000 in your browser for the frontend.

Backend runs on http://localhost:5000/api/.
